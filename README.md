# Prosposta, como deve ser o projeto?

O objetivo deste projeto é criar um **pacote em Python**.

Mas afinal, **o que é um pacote?**

Um pacote é uma forma organizada de reunir vários arquivos Python que trabalham juntos para resolver um mesmo problema. Em vez de deixar todo o código em um único arquivo, vocês irão separar funções, módulos e responsabilidades, criando um projeto muito mais profissional e fácil de manter.

Então, para o seu projeto, cada dupla poderá escolher o nível de dificuldade que desejar.

| **Nível**         | **O que o projeto deve cumprir**                                                                             |
| ----------------- | ------------------------------------------------------------------------------------------------------------ |
| **Básico**        | Criar um pacote que lide com criação e manipulação de sequências.                                            |
| **Intermediário** | Desenvolver o mesmo pacote, porém permitindo manipulação de arquivos de anotação.                            |
| **Avançado**      | Cumprir todos os requisitos anteriores e aplicar também um padrão de organização de código ([Design Patterns Exemplos](https://refactoring.guru/pt-br/design-patterns)). |

### Como escolher o nível?

**Básico** → Ideal para quem quer consolidar o conteúdo das aulas de nivelamento (conjuntos, controles de fluxo, funções, e Git/Github).

**Intermediário** → Para quem já se sente confortável com os conceitos do nível anterior e quer das um passo a mais no seu projeto com a integração de manipulações de arquivos de anotação.

**Avançado** → Para quem já domina os conceitos dos níveis anteriores e quer estruturar o projeto de forma mais profissional, aplicando padrões de projeto e boas práticas de organização de software.

> Independentemente do nível escolhido, o objetivo principal é construir um projeto funcional e bem organizado.
